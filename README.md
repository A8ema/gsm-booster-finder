# GSM Booster Direction Finder

Приложение для Android для поиска оптимального направления установки антенны GSM-репитера/усилителя сигнала.

## Функции
- Измерение уровня GSM/LTE сигнала в реальном времени
- Визуальная индикация силы сигнала (RSRP/RSRQ/SS)
- Удобный интерфейс для поиска направления с максимальным сигналом
- Поддержка нескольких сетевых технологий

## Установка
Для сборки APK используется GitHub Actions (workflow_dispatch).

## Требования
- Android 7.0+
- Разрешения на доступ к информации о сети
